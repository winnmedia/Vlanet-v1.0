⚠️ 즉시 해결이 필요한 심각한 이슈

1. 영상 업로드 API 완전 미구현 Critical

영상 업로드 엔드포인트가 존재하지 않아 405 Method Not Allowed 에러 발생

• feedbacks/urls.py에 upload 경로 없음
• feedbacks/views.py에 FeedbackUpload 클래스 없음
• 핵심 기능 완전 불가 상태

2. 파일 업로드 보안 검증 부재 Critical

파일 크기, 타입, 이름 검증 로직이 전혀 구현되지 않음

• 악성 파일 업로드 가능
• 서버 리소스 고갈 위험
• 보안 취약점 심각

3. 대용량 파일 처리 미구현 High

비디오 파일 청크 업로드 및 스트리밍 처리 없음

• 대용량 비디오 업로드 불가
• 타임아웃 에러 발생 예상
• 사용자 경험 심각하게 저하
