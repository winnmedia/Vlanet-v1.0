# 비디오 플레이어 성능 테스트 가이드

## 브라우저 테스트 실행 방법

1. **개발 서버 실행**
   ```bash
   cd /home/winnmedia/VideoPlanet/vridge_front
   npm start
   ```

2. **브라우저에서 피드백 페이지 접속**
   - http://localhost:3000/Login 에서 로그인 (q@q.com / q)
   - 프로젝트 목록에서 아무 프로젝트나 선택
   - 피드백 페이지로 이동

3. **개발자 도구 열기**
   - F12 또는 마우스 우클릭 → 검사
   - Console 탭으로 이동

4. **성능 테스트 스크립트 실행**
   - `/home/winnmedia/VideoPlanet/vridge_front/src/tests/browser-performance-test.js` 파일의 내용을 복사
   - 브라우저 콘솔에 붙여넣고 Enter

5. **테스트 명령어 실행**
   ```javascript
   // 전체 성능 테스트 실행
   monitor.runTests()
   
   // 실시간 모니터링 시작 (ESC로 중지)
   monitor.startRealTimeMonitoring()
   
   // 수집된 메트릭 확인
   monitor.metrics
   ```

- **프레임 드롭**: 재생 중 드롭된 프레임 수
- **메모리 사용량**: JavaScript 힙 메모리 사용량

- **버튼 기능**: "현재 시점에 피드백" 버튼 등 기능 테스트

## 주요 성능 이슈 및 해결 방안

### 1. CSS 파일 과다 (18개 파일)
**문제**: 초기 로딩 시간 증가
**해결**: CSS 파일 통합으로 HTTP 요청 감소

### 2. 컴포넌트 크기 (1820줄)
**문제**: JavaScript 파싱 시간 증가
**해결**: 컴포넌트 분할로 코드 스플리팅

### 3. 비디오 프리로딩 미설정
**문제**: 첫 프레임 표시 지연
**해결**: preload="metadata" 속성 추가

## 예상 성능 개선

- CSS 통합: 200-500ms 빠른 초기 로드
- 컴포넌트 분할: 30-40% 빠른 JS 파싱
- 비디오 프리로딩: 1-2초 빠른 비디오 시작
- CDN 도입 시: 50-70% 빠른 비디오 전송
