## 3. 작동하지 않는 기능 (❌)

### 3.1 JWT 인증 문제
- **현상**: JWT 토큰은 발급되지만 API 요청 시 401 NEED_ACCESS_TOKEN 에러
- **영향받는 API**:
  - `/api/users/me/` - 현재 사용자 정보
  - `/api/projects/` - 프로젝트 목록 조회
  - `/api/users/mypage/` - 마이페이지 정보
- **특이사항**: 
  - curl로 직접 테스트하면 정상 작동
  - 프로필 업데이트 API는 같은 인증 방식인데 정상 작동

### 3.2 프로젝트 관리
- **프로젝트 생성**: 400 에러 - "필수 데이터가 누락되었습니다"
  - 원인: 요청 데이터 형식 불일치 가능성

### 3.3 미구현 API
- 대부분의 마이페이지 관련 API (404)
- 피드백 관련 API
- WebSocket 관련 API

## 5. 주요 문제점 및 권장사항

### 5.1 JWT 인증 문제 (최우선)
- **문제**: axios를 통한 API 요청 시 JWT 인증 실패
- **권장사항**: 
  - 서버 로그 확인 필요
  - axios 요청 헤더와 curl 요청 헤더 비교
  - CORS 설정 확인

### 5.2 프로젝트 생성 API
- **문제**: 필수 데이터 검증 실패
- **권장사항**: API 문서 확인 및 요청 데이터 형식 수정

### 5.3 미구현 기능
