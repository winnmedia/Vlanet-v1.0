프로젝트 생성 페이지 디버깅

브라우저 콘솔(F12)을 열고 다음 단계를 수행하세요:

  1. http://localhost:3000/ProjectCreate 페이지 열기
  2. 필수 정보 입력 (프로젝트명, 설명, 담당자, 의뢰처)
  3. 등록 버튼 클릭
  4. 콘솔에 나타나는 로그 확인

예상되는 콘솔 로그:

[ProjectCreate] CreateBtn clicked!
[ProjectCreate] Current state: {...}
[ProjectCreate] createProjectWithDebounce called!
[ProjectCreate] Pre-checks: {...}
[ProjectCreate] Starting atomic project creation...
[ProjectCreate] Atomic creation data: {...}
[ProjectCreate] Calling CreateProjectAPI...

문제가 될 수 있는 부분:

  • 토큰이 없거나 만료됨 → 401 에러
  • 백엔드 서버 연결 실패 → 네트워크 에러
  • 날짜 형식 문제 → 400 에러
  • 프로젝트명 중복 → 409 에러
