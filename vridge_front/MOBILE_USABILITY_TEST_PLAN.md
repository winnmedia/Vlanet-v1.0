# VideoPlanet 모바일 사용성 테스트 플랜

**작성자**: Uxi (UX Researcher)

**목표**: 모바일 사용성 개선 효과 측정

## 1. 테스트 개요

### 1.1 테스트 목표
- Viewport 설정 개선 효과 확인
- 모바일 주요 태스크 성공률 측정
- 페인 포인트 식별 및 개선사항 도출
- 이탈률 감소 효과 검증

### 1.2 테스트 참가자
- 주 타겟: 비디오 제작 업계 종사자 5명
- 보조 타겟: 일반 사용자 3명
- 연령대: 25-45세
- 모바일 사용 숙련도: 중급 이상

### 1.3 테스트 환경
- 기기: iPhone 12/13, Galaxy S21/S22, 저사양 Android
- 네트워크: 5G, 4G, 3G 환경
- 브라우저: Safari, Chrome Mobile
- 장소: 실내/실외, 이동 중 환경

## 2. 테스트 시나리오

### 2.1 시나리오 1: 첫 방문 및 로그인

**목표**: 사용자가 처음 VideoPlanet에 접속하여 로그인하기까지의 경험

```
1. Google에서 "VideoPlanet" 검색
2. 사이트 접속
3. 회원가입 또는 로그인 진행
4. 대시보드 진입
```

**측정 항목**:
- 페이지 로드 시간
- 화면 확대/축소 횟수
- 로그인 시도 횟수
- 완료까지 소요 시간
- 오류 발생 횟수

### 2.2 시나리오 2: 비디오 피드백 제공

**목표**: 촬영 현장에서 비디오를 확인하고 피드백 제공

```
1. 프로젝트 목록에서 해당 프로젝트 선택
2. 피드백 페이지 진입
3. 비디오 재생 (30초 지점)
4. 피드백 작성 및 저장
5. 다음 비디오로 이동
```

**측정 항목**:
- 비디오 로듩 시간
- 플레이어 컨트롤 사용 성공률
- 피드백 입력 소요 시간
- 키보드로 인한 화면 이동 횟수
- 작업 완료율

### 2.3 시나리오 3: 프로젝트 관리

**목표**: 새 프로젝트 생성 및 팀원 초대

```
1. 새 프로젝트 생성 버튼 클릭
2. 프로젝트 정보 입력
3. 팀원 초대 (이메일 입력)
4. 일정 설정
5. 프로젝트 생성 완료
```

**측정 항목**:
- 각 단계별 소요 시간
- 입력 필드 사용성
- 오류 발생 빈도
- 작업 포기율

## 3. 측정 지표

### 3.1 정량적 지표

| 지표 | 현재 | 목표 | 측정 방법 |
|------|------|------|----------|
| 모바일 이탈률 | 70% | 50% | Google Analytics |
| 태스크 성공률 | 30% | 70% | 테스트 관찰 |
| 페이지 로드 시간 | 8초 | 3초 | Performance API |
| 화면 확대 횟수 | 5회 | 0회 | 테스트 관찰 |
| 터치 오류율 | 40% | 10% | 테스트 로그 |

### 3.2 정성적 지표

- **사용자 만족도** (SUS - System Usability Scale)
- **작업 난이도** (1-7 스케일)
- **추천 의향** (NPS - Net Promoter Score)
- **감정 반응** (긍정/부정/중립)

## 4. 테스트 진행 방법

### 4.1 사전 준비
1. 테스트 환경 구성
2. 녹화 장비 준비
3. 테스트 계정 생성
4. 테스트 데이터 준비

### 4.2 테스트 진행
1. **소개** (5분)

   - Think Aloud 방법 사용

3. **인터뷰** (10분)
   - 전반적 경험 평가
   - 주요 문제점 파악
   - 개선 아이디어 수집

2. 태스크별 성공률 계산

4. 개선 우선순위 도출
