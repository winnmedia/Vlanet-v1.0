# VideoPlanet 사용자 여정 기반 통합 테스트 계획

## 🎯 목표
- 모든 핵심 기능을 MECE(Mutually Exclusive, Collectively Exhaustive) 방식으로 분석
- 사용자 관점에서 실제 사용 시나리오를 기반으로 오류 검증
- 단순 증상이 아닌 근본 원인을 찾아내는 체계적 접근

## 📊 사용자 페르소나

### 1. 신규 사용자 (New User)
- 첫 방문자
- 회원가입 필요
- 서비스 이해도 낮음

### 2. 일반 사용자 (Regular User)
- 프로젝트 생성/관리
- 피드백 주고받기
- 협업 기능 사용

### 3. 관리자 (Admin)
- 사용자 관리
- 시스템 모니터링
- 데이터 분석

## 🗺️ 핵심 사용자 여정 (Critical User Journeys)

### Journey 1: 회원가입 및 온보딩
```
시작 → 홈페이지 → 회원가입 → 이메일 인증 → 첫 로그인 → 대시보드
```
**테스트 포인트:**
- [ ] 홈페이지 로딩 및 CTA 버튼 작동
- [ ] 회원가입 폼 유효성 검증
- [ ] 이메일 중복 체크
- [ ] 비밀번호 강도 검증
- [ ] 이메일 인증 프로세스
- [ ] 첫 로그인 후 리다이렉션

### Journey 2: 프로젝트 생성 및 관리
```
로그인 → 대시보드 → 프로젝트 생성 → 상세 정보 입력 → 저장 → 프로젝트 목록
```
**테스트 포인트:**
- [ ] 프로젝트 생성 버튼 접근성
- [ ] 필수 필드 검증
- [ ] 프로젝트명 중복 체크
- [ ] 파일 업로드 기능
- [ ] 저장 후 데이터 영속성
- [ ] 목록 페이지 렌더링

### Journey 3: 피드백 시스템
```
프로젝트 선택 → 피드백 요청 → 링크 공유 → 피드백 수신 → 응답 확인
```
**테스트 포인트:**
- [ ] 피드백 페이지 접근 권한
- [ ] 실시간 업데이트 (WebSocket)
- [ ] 미디어 파일 재생
- [ ] 피드백 작성/수정/삭제
- [ ] 알림 시스템

### Journey 4: 비디오 기획
```
프로젝트 → 비디오 기획 → AI 기능 사용 → 콘티 생성 → 내보내기
```
**테스트 포인트:**
- [ ] AI 기능 호출 및 응답
- [ ] 콘티 생성 프로세스
- [ ] 내보내기 포맷 옵션
- [ ] 자동 저장 기능

### Journey 5: 관리자 기능
```
관리자 로그인 → 대시보드 → 사용자 관리 → 시스템 모니터링
```
**테스트 포인트:**
- [ ] 관리자 권한 검증
- [ ] 사용자 목록 페이지네이션
- [ ] 통계 데이터 정확성
- [ ] 이메일 모니터링

## 🔍 MECE 기반 기능 분류

### 1. 인증/권한 (Authentication & Authorization)
- **회원가입**: 이메일, 소셜 로그인
- **로그인**: 일반, 소셜, 자동 로그인
- **비밀번호**: 재설정, 변경
- **세션 관리**: 토큰 갱신, 로그아웃

### 2. 데이터 관리 (Data Management)
- **생성**: 프로젝트, 피드백, 비디오 기획
- **읽기**: 목록 조회, 상세 조회
- **수정**: 정보 업데이트, 상태 변경
- **삭제**: 소프트 삭제, 하드 삭제

### 3. 협업 기능 (Collaboration)
- **공유**: 링크 생성, 권한 설정
- **실시간 통신**: WebSocket, 폴링
- **알림**: 이메일, 인앱 알림

### 4. 미디어 처리 (Media Processing)
- **업로드**: 이미지, 비디오
- **재생**: 스트리밍, 다운로드
- **변환**: 썸네일 생성, 포맷 변환

### 5. AI 기능 (AI Features)
- **텍스트 생성**: 기획안, 콘티
- **분석**: 콘텐츠 분석, 추천

## 🐛 오류 패턴 분류

### 1. 클라이언트 사이드 오류
- **렌더링 오류**: JSX syntax, 조건부 렌더링
- **상태 관리**: Redux, 로컬 state 불일치
- **라우팅**: 잘못된 경로, 권한 체크 실패

### 2. 서버 사이드 오류
- **API 오류**: 500 에러, 타임아웃
- **데이터베이스**: 연결 실패, 쿼리 오류
- **인증**: 토큰 만료, 권한 부족

### 3. 네트워크 오류
- **CORS**: 교차 출처 요청 차단
- **연결**: 네트워크 불안정, 타임아웃

### 4. 비즈니스 로직 오류
- **검증 실패**: 잘못된 입력값
- **상태 불일치**: 예상과 다른 상태
- **동시성**: 레이스 컨디션

## 📝 테스트 실행 계획

### Phase 1: 자동화 테스트 스크립트 개발
1. Playwright 기반 E2E 테스트
2. 각 여정별 시나리오 스크립트
3. 오류 캡처 및 스크린샷

### Phase 2: 수동 테스트 체크리스트
1. 각 기능별 상세 테스트 케이스
2. 엣지 케이스 시나리오
3. 크로스 브라우저 테스트

### Phase 3: 오류 분석 및 근본 원인 추적
1. 오류 로그 수집 및 분류
2. 패턴 인식 및 공통 원인 파악
3. 의존성 맵핑 및 영향 분석

### Phase 4: 통합 모니터링
1. 실시간 오류 대시보드
2. 성능 메트릭 추적
3. 사용자 행동 분석

## 🎯 성공 지표
- 모든 핵심 여정 100% 완료 가능
- 오류율 1% 미만
- 평균 응답 시간 2초 이내
- 사용자 만족도 90% 이상
