- **프론트엔드**: http://localhost:3001 (Next.js)

### 2. 테스트 계정
- **이메일**: demo@test.com
- **비밀번호**: demo1234

## 📋 테스트 시나리오

### 1️⃣ 로그인 테스트
1. http://localhost:3001/Login 접속
2. 위 테스트 계정으로 로그인
3. **예상 결과**: 
   - ✅ 로그인 성공 → CmsHome 페이지로 이동
   - ✅ 우측 상단에 사용자 닉네임 표시

### 2️⃣ 프로젝트 생성 테스트
1. 로그인 후 "프로젝트 생성" 버튼 클릭
2. 필수 정보 입력:
   - 프로젝트명: "테스트 영상 프로젝트"
   - 고객사: "테스트 고객사"
   - 담당자: "데모유저"
3. **예상 결과**: 
   - ✅ 2초 이내 프로젝트 생성 완료
   - ✅ 프로젝트 목록에 새 프로젝트 표시

### 3️⃣ 영상 업로드 및 피드백 테스트
1. 생성한 프로젝트 클릭 → 피드백 페이지 이동
2. "영상 업로드" 버튼 클릭
3. 테스트 영상 파일 선택 (600MB 이하)
4. **예상 결과**:
   - ✅ 업로드 진행률 표시
   - ✅ 업로드 완료 후 영상 재생 가능

### 4️⃣ 피드백 작성 테스트
1. 영상 재생 중 특정 시점에서 일시정지
2. "시점 피드백" 버튼 클릭
3. 피드백 내용 작성 (예: "이 부분 전환이 빠릅니다")
4. **예상 결과**:
   - ✅ 피드백이 해당 시간에 마커로 표시
   - ✅ 우측 피드백 목록에 즉시 반영

### 5️⃣ 영상 기획 페이지 테스트
1. 좌측 메뉴에서 "영상 기획" 클릭
2. 새 기획안 작성 시작
3. **예상 결과**:
   - ✅ AI 지원 기능 활성화
   - ✅ 스토리보드 자동 생성

### 6️⃣ 마이페이지 테스트
1. 우측 상단 프로필 → "마이페이지" 클릭
2. 프로필 정보 확인
3. **예상 결과**:
   - ✅ 사용자 정보 정확히 표시
   - ✅ 참여 프로젝트 목록 표시

## 🚀 성능 체크리스트

각 작업의 목표 시간:
- [ ] 페이지 로드: < 1초
- [ ] 로그인 응답: < 0.5초
- [ ] 프로젝트 생성: < 2초
- [ ] 피드백 등록: < 1초
- [ ] 영상 재생 시작: < 3초

## ⚠️ 주의사항

1. **캐시 초기화**: 테스트 전 브라우저 캐시 삭제 권장
2. **콘솔 확인**: 개발자 도구(F12)에서 오류 메시지 확인
3. **네트워크 탭**: API 호출 성공 여부 확인
